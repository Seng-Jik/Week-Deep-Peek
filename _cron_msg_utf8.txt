## 每周深度一瞥（全自动流程版）

这是每周五晚的固定栏目。请严格按照以下步骤执行，不要跳过任何一步。

### 前置须知
- 本期序号通过读取目录中已有的序号文件自动计算（当前最新序号 + 1）
- GitHub 仓库: git@github.com:Seng-Jik/Week-Deep-Peek.git
- GitHub Pages: https://seng-jik.github.io/Week-Deep-Peek/
- 写作前先用 web_search 搜集素材

### 第一步：搜集素材
1. 使用 web_search 搜索本周有趣的跨领域话题、新技术、思想类文章
2. 使用 web_fetch 阅读具体的文章/博客
3. 基于实时搜索到的材料策划内容，不要只靠训练记忆

### 第二步：写作
写一篇深度一瞥推送，包含三个部分：
1. 广度拓展（主菜） - 选一个兴逸完全不了解的领域，浓缩入门漫游。每周主题必须完全不同大类。涵盖：该领域是干什么的、为什么值得关注、关键人物/事件/概念、与已有兴趣（游戏开发、AI、编程、音乐作曲）的交叉点。
2. 思维燃料（配菜） - 一个有趣的概念/悖论/思维框架。
3. 哲学/历史随笔（甜点） - 一篇哲学/历史随笔或反思性文章。

写作规则：
- 每板块正文百来字，内容丰满
- 给一对不给一个：每个观点配上批判者、对立学派或后继修正版
- 追根溯源：每个观点说明来由、后续社会反响、后继者的延伸/批评
- 广度优先，有意思大于有深度
- 中文自然有性格，不要AI腔

### 第三步：保存文件
将全文以 Markdown 保存至 D:\Vim\深度一瞥\，文件命名格式：{序号}-{主题}-{日期}.md

### 第四步：更新 index.md
1. 读取 D:\Vim\深度一瞥\index.md
2. 在目录最顶部插入新一期条目（参照前面几期的表格格式），最新在上
3. 首页的最新一期直达链接也要更新

### 第五步：Git 同步
执行以下命令提交并推送至 GitHub：
`
cd D:\Vim\深度一瞥 && git add -A && git commit -m "第{序号}期 - {主题}" && git pull --rebase origin main && git push origin main
`

### 第六步：输出推送通知（最重要！）
你的最终输出只能是以下格式的简短通知，不要输出文章全文：

🔗 第{序号}期 · {主题} · {日期}
一句话简介：{一句话概括本期亮点}
直达：https://seng-jik.github.io/Week-Deep-Peek/
